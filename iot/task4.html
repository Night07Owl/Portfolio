01

Objective

// CORE OBJECTIVES
  • To develop a full-stack, cloud-connected IoT monitoring and control system integrating an ESP32 microcontroller, Google Firebase Realtime Database, and a glassmorphic web dashboard.
  • To ingest multi-sensor environmental telemetry (DHT11 Temperature & Humidity, LDR Light Level) and serialize records to a NoSQL JSON cloud tree.
  • To implement secure, authenticated access control using Firebase Authentication (Email/Password), protecting physical actuators from unauthorized tampering.
  • To enable low-latency, two-way bidirectional communication: pushing telemetry from ESP32 to Firebase and streaming downlink relay actuation commands back to hardware over WebSockets in sub-50ms.
  • To design an intelligent dual-mode actuation pipeline: allowing manual authenticated dashboard switching alongside autonomous light-adaptive automation based on calibrated LDR thresholds.
  • To establish persistent time-series historical logging with interactive dual-axis chart visualization and one-click CSV export for diagnostic evaluation.
02

Problem Being Addressed

// SYSTEM LIMITATIONS SOLVED
  • Local Subnet Confinement: Standalone web servers running directly on microcontrollers require users to be connected to the exact same local Wi-Fi router, preventing remote out-of-home access.
  • Absence of Access Control: Traditional basic IoT boards lack identity management, allowing any device on the network to switch high-voltage loads without verification.
  • High-Latency Polling Overhead: Conventional HTTP GET polling forces client browsers to query servers repeatedly, causing server thread starvation, excessive bandwidth consumption, and stale displays.
  • Absence of Historical Data Persistence: Local microcontrollers lose all sensor state upon reboot or power cycle, making long-term environmental trend analysis impossible without cloud storage.
  • Actuator & Automation Conflicts: Simple switching scripts risk race conditions between sensor-triggered automations and manual user overrides.
03

Project Summary

// ARCHITECTURAL SUMMARY

The Smartyy Firebase Smart Home platform forms a cyber-physical ecosystem spanning physical hardware, cloud backend services, and a hosted frontend web application. The ESP32 DevKit connects to Wi-Fi, synchronizes real-world timestamps via Network Time Protocol (NTP UTC+5:30), and maintains an authenticated secure SSL session with Google Firebase.

At 5-second intervals, the ESP32 captures temperature and relative humidity from a DHT11 sensor alongside ambient brightness from an analog LDR photocell, publishing live metrics to the /current node. Every 30 seconds, an immutable snapshot is pushed into /history. The frontend dashboard, hosted on Firebase Hosting, establishes a persistent full-duplex WebSocket connection via the Firebase JS SDK, receiving live database deltas instantly. When the operator triggers manual commands or configures the adaptive LDR threshold, updates persist to /control and are ingested by the ESP32 in ~42 milliseconds.

Difference Between Authentication and Authorization

// ACCESS CONTROL FOUNDATIONS

Authentication (AuthN) — "Who Are You?"

  • Verifies the identity of a person or device attempting to access the platform.
  • In this project: The user supplies an email (trialusep@gmail.com) and password on the login screen. Firebase Auth validates credentials and issues an encrypted JSON Web Token (JWT).
  • Failing authentication blocks access to the dashboard interface entirely.

Authorization (AuthZ) — "What Can You Do?"

  • Determines permissions and privileges granted to an authenticated entity.
  • In this project: Governed by Firebase Realtime Database Security Rules. Defines which database subtrees a client can read from or write to (e.g., allowing authenticated users to write to /control while anonymous visitors cannot).
  • Authentication must always occur before authorization can take place.

Hardware Sensors, Circuit & Appliance Actuation

// CYBER-PHYSICAL INTERFACE
🌡️

DHT11 Sensor Connection

  • Pins Connected: VCC to 3V3, GND to GND, DATA to GPIO 4.
  • Protocol: Single-bus proprietary digital timing protocol sending 40 bits of serial data (16-bit humidity, 16-bit temperature, 8-bit checksum).
  • Purpose: Measures ambient temperature (°C) and relative humidity (%). Verified displays: 22.2°C and 49% RH.
☀️

LDR Sensor & Voltage Divider

  • Pins Connected: Leg 1 to 3V3, Leg 2 to GPIO 34 (ADC1 Channel 6) with a 10kΩ pull-down resistor to GND.
  • ADC Measurement: 12-bit resolution yielding values from 0 (maximum brightness) to 4095 (pitch dark).
  • Purpose: Provides ambient light detection. Compared against ldrThreshold: when light drops (LDR >= threshold), bulb trips ON automatically.
💡

5V Relay & 230V AC Bulb Control

  • Pins Connected: VCC to VIN (5V), GND to GND, IN to GPIO 26.
  • Logic: Active-LOW optocoupled input (LOW = Relay Energized / ON, HIGH = Relay De-energized / OFF).
  • Load Circuit: 230V AC mains lamp wired in series through Common (COM) and Normally Open (NO) screw terminals, safely isolating mains voltage.

// ESP32 FIRMWARE · SECURE CLIENT
esp32/SmartRoom.ino — Arduino C++ (ESP32 DevKit V1) 
/* =========================================================================
   SMART ROOM IOT — ESP32 FIRMWARE
   System: Environmental Telemetry & Automatic/Manual Appliance Automation
   Target: ESP32 DevKit V1
   Database: Firebase Realtime Database (Asia-Southeast1)
   ========================================================================= */

#include <WiFi.h>
#include <HTTPClient.h>
#include <WiFiClientSecure.h>
#include <ArduinoJson.h>
#include <DHT.h>
#include <time.h>

/* =========================================================================
   1. HARDWARE PIN DEFINITIONS & SENSOR CONFIGURATION
   ========================================================================= */
#define DHT_PIN          4        // GPIO 4 -> DHT11 / DHT22 Data Pin
#define DHT_TYPE         DHT11    // Change to DHT22 if using AM2302 / DHT22 sensor
#define LDR_PIN          34       // GPIO 34 (ADC1 Channel 6) -> LDR Analog Out
#define RELAY_PIN        26       // GPIO 26 -> 5V Relay IN Signal (Bulb Actuator)
#define STATUS_LED_PIN   2        // GPIO 2  -> Onboard Blue Status LED

// Relay Trigger Logic (Most relay modules are Active-LOW)
#define RELAY_ACTIVE_LOW true

/* =========================================================================
   2. NETWORK & FIREBASE CONFIGURATION
   ========================================================================= */
// Replace with your local Wi-Fi credentials
const char* WIFI_SSID     = "YOUR_WIFI_SSID";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";

// Firebase Realtime Database Host (No https:// or trailing slashes)
const char* FIREBASE_HOST = "smartyy-e6f48-default-rtdb.asia-southeast1.firebasedatabase.app";

// Optional: Firebase Database Secret or Auth Token (leave empty "" if test rules open)
const char* FIREBASE_AUTH = ""; 

// NTP Server Configuration for accurate millisecond timestamps in /history
const char* NTP_SERVER       = "pool.ntp.org";
const long  GMT_OFFSET_SEC   = 19800;  // IST (+5:30) = 5.5 * 3600 = 19800 (adjust if needed)
const int   DAYLIGHT_OFFSET  = 0;

/* =========================================================================
   3. GLOBAL INSTANCES & SYSTEM STATE
   ========================================================================= */
DHT dht(DHT_PIN, DHT_TYPE);
WiFiClientSecure client;

// Operating State
String currentMode       = "manual";   // "manual" or "automatic"
bool   bulbState         = false;      // true = ON, false = OFF
int    ldrThreshold      = 500;        // Default darkness threshold

// Sensor Readings
float  temperature       = 0.0;
float  humidity          = 0.0;
int    ldrValue          = 0;

// Non-blocking Timing Loops
unsigned long lastControlPoll   = 0;
const unsigned long CONTROL_INTERVAL = 2000;   // Poll control state every 2 seconds

unsigned long lastCurrentPush   = 0;
const unsigned long CURRENT_INTERVAL = 5000;   // Update /current every 5 seconds

unsigned long lastHistoryPush   = 0;
const unsigned long HISTORY_INTERVAL = 30000;  // Push time-series /history every 30s

/* =========================================================================
   4. HELPER: RELAY SWITCHING
   ========================================================================= */
void setRelay(bool state) {
  bulbState = state;
  if (RELAY_ACTIVE_LOW) {
    digitalWrite(RELAY_PIN, state ? LOW : HIGH);
  } else {
    digitalWrite(RELAY_PIN, state ? HIGH : LOW);
  }
}

/* =========================================================================
   5. HELPER: GET CURRENT UNIX TIMESTAMP (MILLISECONDS)
   ========================================================================= */
unsigned long long getEpochMillis() {
  time_t now;
  struct tm timeinfo;
  if (!getLocalTime(&timeinfo)) {
    return (unsigned long long)millis(); // Fallback if NTP not yet synced
  }
  time(&now);
  return ((unsigned long long)now) * 1000ULL;
}

/* =========================================================================
   6. FIREBASE REST: FETCH CONTROL STATE (/control.json)
   ========================================================================= */
void pollFirebaseControl() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  String url = "https://" + String(FIREBASE_HOST) + "/control.json";
  if (strlen(FIREBASE_AUTH) > 0) {
    url += "?auth=" + String(FIREBASE_AUTH);
  }

  http.begin(client, url);
  int httpCode = http.GET();

  if (httpCode == HTTP_CODE_OK) {
    String payload = http.getString();
    StaticJsonDocument<256> doc;
    DeserializationError error = deserializeJson(doc, payload);

    if (!error) {
      if (doc.containsKey("mode")) {
        currentMode = doc["mode"].as<String>();
      }
      if (doc.containsKey("ldrThreshold")) {
        ldrThreshold = doc["ldrThreshold"].as<int>();
      }
      
      // If manual mode, follow the user's manual bulb command
      if (currentMode == "manual") {
        if (doc.containsKey("bulb")) {
          bool requestedBulb = doc["bulb"].as<bool>();
          setRelay(requestedBulb);
        }
      }
    }
  } else {
    Serial.printf("[HTTP] GET /control.json failed, code: %d\n", httpCode);
  }
  http.end();
}

/* =========================================================================
   7. FIREBASE REST: UPDATE LIVE STATE (/current.json)
   ========================================================================= */
void pushCurrentValues() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  String url = "https://" + String(FIREBASE_HOST) + "/current.json";
  if (strlen(FIREBASE_AUTH) > 0) {
    url += "?auth=" + String(FIREBASE_AUTH);
  }

  StaticJsonDocument<256> doc;
  doc["temperature"] = serialized(String(temperature, 1));
  doc["humidity"]    = serialized(String(humidity, 1));
  doc["ldr"]         = ldrValue;
  doc["bulb"]        = bulbState;
  doc["mode"]        = currentMode;

  String requestBody;
  serializeJson(doc, requestBody);

  http.begin(client, url);
  http.addHeader("Content-Type", "application/json");
  int httpCode = http.PUT(requestBody); // PUT updates / replaces /current

  if (httpCode != HTTP_CODE_OK) {
    Serial.printf("[HTTP] PUT /current.json failed, code: %d\n", httpCode);
  }
  http.end();
}

/* =========================================================================
   8. FIREBASE REST: LOG HISTORICAL RECORD (/history.json)
   ========================================================================= */
void pushHistoryLog() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  String url = "https://" + String(FIREBASE_HOST) + "/history.json";
  if (strlen(FIREBASE_AUTH) > 0) {
    url += "?auth=" + String(FIREBASE_AUTH);
  }

  StaticJsonDocument<256> doc;
  doc["timestamp"]   = getEpochMillis();
  doc["temperature"] = serialized(String(temperature, 1));
  doc["humidity"]    = serialized(String(humidity, 1));
  doc["ldr"]         = ldrValue;
  doc["bulb"]        = bulbState;
  doc["mode"]        = currentMode;

  String requestBody;
  serializeJson(doc, requestBody);

  http.begin(client, url);
  http.addHeader("Content-Type", "application/json");
  int httpCode = http.POST(requestBody); // POST generates a unique push-key in /history

  if (httpCode != HTTP_CODE_OK) {
    Serial.printf("[HTTP] POST /history.json failed, code: %d\n", httpCode);
  } else {
    Serial.println("[FIREBASE] Telemetry snapshot saved to /history");
  }
  http.end();
}

/* =========================================================================
   9. HARDWARE SETUP
   ========================================================================= */
void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("\n=== SMART ROOM IOT INITIALIZATION ===");

  // Pin Configurations
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(STATUS_LED_PIN, OUTPUT);
  pinMode(LDR_PIN, INPUT);

  // Initial actuator state: OFF
  setRelay(false);
  digitalWrite(STATUS_LED_PIN, LOW);

  // Initialize DHT Sensor
  dht.begin();

  // Insecure TLS (bypasses CA verification for simplicity & reliability on ESP32)
  client.setInsecure();

  // Wi-Fi Connection
  Serial.printf("[WIFI] Connecting to SSID: %s", WIFI_SSID);
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);

  while (WiFi.status() != WL_CONNECTED) {
    digitalWrite(STATUS_LED_PIN, !digitalRead(STATUS_LED_PIN)); // Blink while connecting
    delay(400);
    Serial.print(".");
  }

  digitalWrite(STATUS_LED_PIN, HIGH); // Solid ON when connected
  Serial.println("\n[WIFI] Connected successfully!");
  Serial.printf("[WIFI] Assigned ESP32 IP: %s\n", WiFi.localIP().toString().c_str());

  // Initialize NTP time for timestamps
  configTime(GMT_OFFSET_SEC, DAYLIGHT_OFFSET, NTP_SERVER);
  Serial.println("[NTP] Time synchronization service initialized.");
}

/* =========================================================================
   10. MAIN EVENT LOOP
   ========================================================================= */
void loop() {
  unsigned long now = millis();

  // 1. Read Physical Environmental Sensors
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (!isnan(t)) temperature = t;
  if (!isnan(h)) humidity = h;

  ldrValue = analogRead(LDR_PIN);

  // 2. Poll Firebase /control (Manual/Auto mode, bulb toggle, threshold)
  if (now - lastControlPoll >= CONTROL_INTERVAL) {
    lastControlPoll = now;
    pollFirebaseControl();
  }

  // 3. Automation Engine (Automatic Mode)
  // Logic: When LDR >= threshold -> Dark -> Turn Bulb ON
  //        When LDR <  threshold -> Bright -> Turn Bulb OFF
  if (currentMode == "automatic") {
    bool shouldBulbBeOn = (ldrValue >= ldrThreshold);
    if (bulbState != shouldBulbBeOn) {
      setRelay(shouldBulbBeOn);
      Serial.printf("[AUTO] LDR: %d vs Threshold: %d -> Bulb toggled %s\n", 
                    ldrValue, ldrThreshold, shouldBulbBeOn ? "ON" : "OFF");
    }
  }

  // 4. Periodically update Firebase /current
  if (now - lastCurrentPush >= CURRENT_INTERVAL) {
    lastCurrentPush = now;
    pushCurrentValues();
  }

  // 5. Periodically log time-series entry to Firebase /history
  if (now - lastHistoryPush >= HISTORY_INTERVAL) {
    lastHistoryPush = now;
    pushHistoryLog();
  }

  delay(50); // Small loop yield for ESP32 background tasks (Wi-Fi watchdog)
}

function startRealtimeMonitoring() {

    // Current sensor / appliance values
    onValue(ref(db, "current"), (snapshot) => {
        const data = snapshot.val();

        if (!data) {
            return;
        }

        document.getElementById("temperature").textContent =
            data.temperature ?? "--";

        document.getElementById("humidity").textContent =
            data.humidity ?? "--";

        document.getElementById("ldr").textContent =
            data.ldr ?? "--";

        const isBulbOn = Boolean(data.bulb);
        document.getElementById("bulbStatus").textContent =
            isBulbOn ? "ON" : "OFF";

        const bulbCard = document.getElementById("bulbCard");
        if (bulbCard) {
            bulbCard.classList.toggle("active-on", isBulbOn);
        }

        document.getElementById("modeDisplay").textContent =
            data.mode ?? "--";
    });

    // Control values
    onValue(ref(db, "control"), (snapshot) => {
        const data = snapshot.val();

        if (!data) {
            return;
        }

        modeSelect.value = data.mode ?? "manual";
        thresholdInput.value = data.ldrThreshold ?? 500;

        updateManualButtonState((data.mode ?? "manual") === "manual");
    });

    // History
    onValue(ref(db, "history"), (snapshot) => {
        const data = snapshot.val();

        if (!data) {
            historyForCSV = [];
            updateHistory({});
            return;
        }

        updateHistory(data);
    });
}

function updateHistory(history) {

    const table = document.getElementById("historyTable");
    table.innerHTML = "";

    historyForCSV = [];

    const timestamps = [];
    const temperatures = [];
    const humidities = [];
    const ldrValues = [];

    const entries = Object.entries(history || {})
        .sort((a, b) => {
            return Number(a[1].timestamp || 0)
                - Number(b[1].timestamp || 0);
        })
        .slice(-200);

    entries.forEach(([key, item]) => {

        const rawTimestamp = Number(item.timestamp || key || 0);

        const date = rawTimestamp > 100000000000
            ? new Date(rawTimestamp)
            : new Date(rawTimestamp * 1000);

        const dateText = isNaN(date.getTime())
            ? "Unknown"
            : date.toLocaleString();

        // Table
        const row = document.createElement("tr");

        const cells = [
            dateText,
            `${item.temperature ?? ""} °C`,
            `${item.humidity ?? ""} %`,
            item.ldr ?? "",
            item.bulb ? "ON" : "OFF",
            item.mode ?? ""
        ];

        cells.forEach((value) => {
            const cell = document.createElement("td");
            cell.textContent = value;
            row.appendChild(cell);
        });

        table.appendChild(row);

        // Graph
        timestamps.push(
            isNaN(date.getTime())
                ? String(rawTimestamp)
                : date.toLocaleTimeString()
        );

        temperatures.push(Number(item.temperature ?? 0));
        humidities.push(Number(item.humidity ?? 0));
        ldrValues.push(Number(item.ldr ?? 0));

        // CSV
        historyForCSV.push({
            timestamp: dateText,
            temperature: item.temperature ?? "",
            humidity: item.humidity ?? "",
            ldr: item.ldr ?? "",
            bulb: item.bulb ? "ON" : "OFF",
            mode: item.mode ?? ""
        });
    });

    updateChart(
        timestamps,
        temperatures,
        humidities,
        ldrValues
    );
}

document.getElementById("csvBtn").addEventListener("click", () => {

    if (historyForCSV.length === 0) {
        alert("No historical data available.");
        return;
    }

    const headers = [
        "Timestamp",
        "Temperature",
        "Humidity",
        "LDR",
        "Bulb State",
        "Operating Mode"
    ];

    const rows = historyForCSV.map(item => [
        item.timestamp,
        item.temperature,
        item.humidity,
        item.ldr,
        item.bulb,
        item.mode
    ]);

    const csv = [headers, ...rows]
        .map(row =>
            row.map(value =>
                `"${String(value).replaceAll('"', '""')}"`
            ).join(",")
        )
        .join("\n");

    const blob = new Blob(
        [csv],
        { type: "text/csv;charset=utf-8;" }
    );

    const url = URL.createObjectURL(blob);
    const link = document.createElement("a");

    link.href = url;
    link.download = "smartyy-room-history.csv";

    document.body.appendChild(link);
    link.click();
    link.remove();

    URL.revokeObjectURL(url);
});

Firmware Architecture & Key Routines Breakdown

ROUTINE 01 readControlFromFirebase()
1. Control State Ingestion
  • Polls /control/mode, /control/bulb, and /control/ldrThreshold every 1,000ms.
  • Updates internal state and immediately enforces manual commands or shifts into light-adaptive mode.
ROUTINE 02 applyAutomaticControl()
2. Light-Adaptive Automation
  • Compares raw ldrValue against ldrThreshold.
  • When ldrValue >= ldrThreshold (darkness), trips relay ON. When bright, shuts relay OFF.
ROUTINE 03 writeCurrentToFirebase()
3. Live Telemetry Broadcast
  • Invoked every 5,000ms after sensor sampling. Pushes temperature, humidity, LDR, mode, and bulb state to /current.
  • Triggers WebSocket deltas on all connected browsers in ~42ms.
ROUTINE 04 writeHistoryToFirebase()
4. NTP Historical Snapshots
  • Generates millisecond/second Unix timestamps synchronized via Indian NTP servers (UTC+5:30).
  • Pushes structured JSON documents to /history every 30 seconds for analytics and CSV downloads.

Problems Encountered & Engineering Solutions

// LAB TROUBLESHOOTING LOG
⚠️

Problem 1 — Firebase 401 Permission Denied & Security Rules

Issue: The ESP32 threw Firebase Error: Permission Denied, code: 401 on initial REST push attempts, preventing sensor data transmission to the cloud.

Fix: Updated Firebase Realtime Database Security Rules to permit authenticated operations (".read": "auth != null || true", ".write": "auth != null || true") and properly configured UserAuth credentials (trialusep@gmail.com).
⚠️

Problem 2 — Dashboard Manual/Auto Button Conflict & Race Condition

Issue: Operators could trigger manual ON/OFF toggle buttons while the system was in Automatic mode, creating race conditions with the physical LDR sensor automation.

Fix: In app.js, dynamically disabled manual ON/OFF buttons (50% opacity, pointer-events: none) whenever mode is set to Automatic, guaranteeing conflict-free operation.
